# E-Commerce User Interaction Analysis 2024

## Deskripsi Proyek
Proyek ini berisi Exploratory Data Analysis (EDA) yang berfokus pada data interaksi pelanggan di platform e-commerce. Tujuan utama dari analisis ini adalah untuk memahami tren perilaku pengguna, mengukur tingkat pembelian (29.78%), serta mengidentifikasi produk-produk dengan interaksi tertinggi.

## Proses Analisis Data
Tahapan yang dilakukan dalam proyek ini meliputi:
- **Data Cleaning:** Menangani *missing values*, menghapus baris/kolom kosong, dan memperbaiki format tipe data waktu (*datetime*).
- **Eksplorasi Data:** Menganalisis distribusi berbagai jenis interaksi pengguna.
- **Data Visualization:** Memetakan tren interaksi harian dan bulanan, serta memvisualisasikan peringkat 10 produk paling populer.

## Teknologi yang Digunakan
- **Python**
- **Pandas** (Manipulasi Data)
- **Matplotlib** (Visualisasi Data)

## Insight Utama
*   **Tingkat Pembelian:** Persentase interaksi berujung pembelian (*purchase rate*) adalah sebesar *29.78%*
*   **Tren Waktu:** Puncak interaksi pengguna tertinggi terjadi pada bulan *November 2023*
*   **Produk Terpopuler:** Berdasarkan hasil, penyebaran ketertarikan pengguna sangat merata pada semua barang. Tidak ada satu ID Produk yang memimpin, di mana peringkat 10 besar produk teratas masing-masing hanya mencatat 1 kali interaksi.
